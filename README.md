# Java Chatting Application 💬

A simple real-time **client-server chatting application** built using  
**Java Socket Programming and Multithreading**.

This project demonstrates how two systems can communicate over a network
using TCP sockets with simultaneous read and write operations.

---

## 🚀 Features
- Real-time message exchange between client and server
- Multithreaded communication (read & write run in parallel)
- Client–Server architecture
- Graceful connection termination using `exit` command

---

## 🛠️ Tech Stack
- Java
- Socket Programming (TCP)
- Multithreading
- I/O Streams

---
